# 提示词条补充记录

## 问题与来源

用户截图中密度笔刷（F8）的正文已更新为包含实时优化及密度贴图显示的长说明；旧版密度说明不足以匹配该完整原文。补接 HTML 入口后仍需对应完整词条，不能把短版说明当作新版长说明已覆盖。本次补充归入正式版 1.0.5。

本次只静态读取本机 2027.0.598 程序，审查编辑模式、工具与面板相关字符串区域。没有启动或操作 RizomUV，也没有修改用户安装或设置。

## 变更

- 补齐截图中的密度系数贴图说明，包括优化后 UV 面积变化、排布与热点匹配、实时优化、视口显示开关。
- 新增 215 段完整提示：笔刷、模式切换与选择转换、自动接缝、循环边、最短路径、纹素密度、组与标签、变换与适配、视口显示、间距预览、场景导入、文件导出、工具栏和首选项等。
- 增加 148 个 HTML 分段词条，覆盖长说明分成段落、标题和列表项后的文本；同时收录去除 Markdown 标记的正文，以匹配 HTML 解析后的内容。
- 统一 5 处仅空白格式不同、译文却不同的旧变体，避免规范化查词因冲突拒绝匹配。
- 正式词典新增 363 条，共 5,213 条，旧英文键全部保留。
- 排除窗口框架内部错误、代码符号、属性路径、无界面模式调试日志等内容，不将二进制里的所有字符串当作界面提示。

密度笔刷正文译文：

> 切换到密度系数贴图绘制模式。绘制后，非零密度系数会在执行优化时改变 UV 多边形的面积。排布也会根据该贴图调整各岛的缩放比例，热点匹配同样会使用它。笔刷面板默认启用“实时优化”，每次笔划都会在绘制时重新优化受影响的岛。使用笔刷时，视口会显示密度系数；可在笔刷面板中关闭“显示密度贴图”以取消显示。
