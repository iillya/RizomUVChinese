# RizomUVChinese 代码审查记录

## 范围

检查运行时生命周期、120 秒模块检测、普通/延迟 IAT 遍历、六个 GDI 接口、HTML 提示、词典解析、原生菜单及署名窗口、启动器、日志、Inno 安装与卸载、打包及工程测试。保留开始审查时的未提交修改；5,213 条词典文件的 SHA-256 在本轮前后完全一致。

本轮没有启动、关闭或操作 RizomUV，没有更新用户安装、修改用户设置、提交或发布。安装测试限定为工程边界程序、打包单元测试和安装器编译；未执行安装器/卸载器事务测试。

## 确认问题与修复

| 问题 | 修复及验证 |
| --- | --- |
| 提示桥接依赖自身 Release 的 `std::wstring` 布局，Debug 布局不同 | 显式构造宿主 32 字节只读字符串描述，继续由宿主分配/释放复制结果；不再把本工程 STL 对象布局传入宿主。Debug 与 Release 回归均通过。 |
| HTML 跨内联标签替换会丢掉正文边缘空白 | 保留已解码的首尾空白与原标签；增加空格、换行、NBSP 边界用例。双语逐词粗体位置仍不保证一致。 |
| 非 BMP 数字实体导致整段拒绝匹配；极长用户译文可无限扩大提示 | 支持有效 Unicode 标量的 UTF-16 代理对，拒绝非法标量；限制输出长度并对超限保留原文。 |
| 可选提示初始化异常会中止其他初始化，并可能让逐次命中统计长期写入 | 隔离可选提示失败，继续 GDI 初始化流程；外层异常停止启动统计。 |
| 每个 GDI 调用先查询 DC，未命中和中文也有无效设备开销 | 先查词，仅在实际替换时检查屏幕/内存 DC；同文映射直接保留原文。保留打印机、元文件、逐字符数组、字形索引和可写缓冲的原语义。设备检查恢复调用前 LastError。 |
| 多次 SetPage 尺寸计算重复分词、分配及转义相同 HTML | 每线程缓存最近一段提示，输入/输出各限制 16,384 字符；词表重建使旧缓存失效。无持续窗口扫描，宿主排版仍每次调用。 |
| HTML 规范化词表再次复制全部译文 | 改为引用正式词典不可变译文，预留查词表容量；明确词典生命周期约束。 |
| 把 Win64 LoadLibraryW 返回指针当作 DWORD 线程退出码 | 改为等待线程完成后确认目标进程已加载指定完整模块路径，避免低 32 位为零时误判；用本工程进程验证模块存在/不存在，不启动宿主。 |
| 启动器重复解析自身目录 | 只解析一次，并处理无法确定目录的错误。 |
| 署名 DIB 的 CPU 读操作未等待 GDI 批处理；渲染失败仍显示并缓存可见状态 | 读取像素前 GdiFlush，字体失败释放资源，图层更新失败时隐藏以便后续重试；删除覆盖前无效的像素清零。 |
| 打包器可接受运行时拒绝的元数据代理字符与深层嵌套 | 与运行时统一 UTF-8 字符与 64 层元数据深度检查。 |
| 编译期间载荷被改变会使清单哈希与实际打包内容不同 | 固定载荷和支持 DLL 的校验快照，编译器只读取快照；内容变化时中止。单元测试验证快照稳定及变化检测。 |
| 权限修复失败前已替换旧安装包 | 在输出目录创建临时成品并完成权限处理，成功后才原子替换；失败时旧安装包保留。 |
| 清理旧实验版卸载记录未核对安装目录 | 仅清理同目录记录；保留其他目录的独立记录。 |
| 升级测试把当前词典误当作固定旧版发行默认 | 测试包显式指定假默认哈希，生产构建禁止该参数；验证隔离测试包编译及生产禁止规则。生产旧默认哈希不变。 |

## 清理与编写规范

删除安装器中生产模式下恒假的旧注册记录分支、无效像素清零和菜单文本缓冲的重复清零；合并各 CMake 目标重复的编译配置，统一 `/W4 /WX /permissive- /utf-8`。保留仍承担数组边界、旧版导入、用户数据保护与失败回退职责的代码。新增 Debug 独立输出选项，正式安装器始终使用 Release 载荷。

## 性能证据

在同一台机器、同一 5,213 条词典及全量语料上比较，七轮取中位数：

| 路径 | 修复前 | 修复后 | 单位 |
| --- | ---: | ---: | --- |
| GDI 显示路径，未命中 | 252 | 72 | ns/调用 |
| GDI 显示路径，已是中文 | 185 | 10 | ns/调用 |
| 连续相同 HTML 的翻译 | 1,932 | 12 | ns/调用 |
| 短命中纯查词 | 84 | 82 | ns/调用 |
| 长命中纯查词 | 1,378 | 1,389 | ns/调用 |
| 混合未命中纯查词 | 286 | 291 | ns/调用 |

纯查词变化接近测量噪声，不宣称加速。HTML 数值只衡量本工程的重复文本翻译，不含宿主复制、窗口绘制或排版；这些微基准不能作为整软件帧率、CPU/GPU 占用或复杂工程性能保证。未修改 UV 算法。完整记录位于 `build/audit-performance-before.txt` 和 `build/audit-performance-after-final.txt`。

## 兼容性与验证

- Release/x64：运行时、启动器、提示、GDI/导入兼容、性能及安装边界程序构建通过，无警告。
- Debug/x64：在独立目录构建运行时、启动器、提示、GDI/导入及安装边界程序；相关回归通过。
- 5,213 条正式词典解析通过；新增提示语料 363 条经真实 HTML 翻译模块全部通过。
- 普通/延迟导入、缺少原始名称表、损坏 RVA、参数转义、稳定查询、原生菜单、事件合并、中文测量与打印/EMF 保护回归通过。
- 字符串桥接、原输入不变、缓存失效、输出别名、实体、超长译文、未知文本及异常清理回归通过。
- 安装支持边界验证真实本地目录、根目录/UNC/设备路径拒绝、x64/x86/坏 PE、缺失文件和树深度/数量上限；只读验证和本工程临时假目录，不执行安装。
- Python 打包检查 4 项通过；隔离安装包编译通过，生产构建拒绝测试专用默认哈希参数。
- 重新静态读取 2018、2022 原始程序和本机 2027 程序，均为 AMD64，均含 DrawTextW、ExtTextOutW、GetTextExtentPoint32W、GetTextExtentExPointW；记录各文件哈希，未启动旧版本。
- 正式运行时依赖 USER32、GDI32、SHELL32、bcrypt、KERNEL32；启动器依赖 USER32、SHELL32、KERNEL32，不要求额外 VC 或 Qt 运行库。
- CMake 对 MSVC 明确要求 AMD64/x64 工具链，避免把 ARM64 的 64 位指针误当成受支持的宿主架构。

HTML 内部入口仍只适配文件哈希已验证的 2027.0.598 构建；其他构建回退到 GDI，不能据此声称全部提示覆盖。2018/2022 本轮只完成静态接口检查；2025 的加载与工程操作是 2026-09 的既往记录。没有当前各版本的逐面板显示、复杂工程或长时间运行验收；实际覆盖安装/卸载事务也未重跑。
