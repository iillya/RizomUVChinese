## 更新内容

- 扩充并审校 2027 界面与提示词典：相比 1.0.4 新增 **1,108 条**、修订 **52 条**映射，词典由 4,128 条增至 **5,236 条**，保留全部旧英文键。
- 补齐密度笔刷长说明、选择模式、UV 集、选择剪贴板、自动保存、导入选项、视口颜色及首选项等标签和提示，统一数据浏览器、3D 网格边界等译法。
- 为经完整性验证的 **2027.0.598** 构建接入 HTML 提示入口，在拆词与排版前翻译整段正文，解决词典已有译文但提示仍为英文的问题。
- 修复提示字符串布局、HTML 实体与格式边界、启动器加载结果判断，减少未命中查词和重复提示翻译的开销。
- 修复 Bilibili 署名与 GitHub 链接的主窗口选择和绘制初始化，增加有限的启动重试及诊断日志。
- 改进安装、更新与卸载的数据保护：保留人工修改的词典和额外文件，新默认词典另存用于对照；安装包使用固定载荷快照、哈希校验及输出权限处理。
- 后台模块检测仍仅在启动后 **120 秒**内运行，到期后扫描线程退出，已接入的汉化继续生效。

## 下载与更新

下载下方 **RizomUVChineseInstaller.exe**。保存工程并退出 RizomUV，选择直接包含 `rizomuv.exe` 的原软件目录覆盖安装，再从“RizomUV 中文版”启动。

人工修改的 `ChineseLauncher\dictionary_zh.json` 会保留，新默认词典位于 `.inno\defaults`，需自行对照合并。`SHA256SUMS.txt` 提供安装包 SHA-256 校验值。

## 兼容性与验证

- Windows 10 1607 及以上的 x64 系统，包括 Windows 11。
- Release 与 Debug 构建、词典加载、GDI 参数保护、HTML 提示及字符串生命周期、安装支持边界和打包校验回归通过。
- 2027.0.598 提示入口已完成离线完整性与 ABI 验证；其他构建保留常规 GDI 汉化，不复用未知内部地址。
- 2018、2022 本轮仅完成静态接口检查；2025 的实际加载验证来自既往记录。本轮未操作 RizomUV，全部面板、署名现场显示及复杂工程尚未逐项验收。
