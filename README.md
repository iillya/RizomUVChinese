# RizomUV 简体中文补丁

为 Windows 版 RizomUV 提供中文菜单、工具面板、选项和提示说明。通过“RizomUV 中文版”启动后生效，原版程序和工程数据保留原样。

当前安装包：**1.0.5** · 正式词典：**5,236 条**。

1.0.5 汇总本轮翻译、提示接入、运行时及安装器修复，相比 1.0.4 新增 1,108 条映射。补齐密度笔刷长说明、选择模式、UV 集与剪贴板、首选项和截图中遗漏的标签，并改善已有译文。详见 [翻译审校](docs/translations-2026-10-14.md)、[提示词条](docs/tooltip-dictionary-2026-10-14.md) 和 [界面标签](docs/dictionary-2026-10-14.md)。

修复提示字符串布局、HTML 格式边界、启动器注入结果判断及打包一致性问题，减少 GDI 未命中路径和重复提示翻译的开销。修复署名链接的主窗口选择与绘制初始化，保留 Bilibili 作者主页和 GitHub 仓库链接。详见 [代码审查](docs/audit-2026-10-14.md) 和 [署名链接记录](docs/credits-2026-10-14.md)。

为已核对的 **2027.0.598** 程序补接 HTML 提示入口：在正文被拆成单词和排版之前翻译整句，解决词典已有译文但提示仍显示英文的问题。此内部入口按程序完整性识别，其他构建不会套用同一地址。实际界面尚需用户重启后验证，详见 [提示路径记录](docs/tooltip-hook-2026-10-14.md)。后台模块检测仍仅在启动后的前 **120 秒**运行，到期后扫描线程退出，已接入的汉化继续生效；之后才首次加载或解析的接口不再自动补接。

## 安装与启动

1. 保存工程，正常退出 RizomUV。
2. 运行 [RizomUVChineseInstaller.exe](dist/RizomUVChineseInstaller.exe)。
3. 选择**直接包含 `rizomuv.exe` 的文件夹**，按向导完成安装。
4. 从桌面或开始菜单打开 **RizomUV 中文版**。

例如软件装在 `C:\Program Files\Rizom Lab\RizomUV 2025.0`，就选择这个目录。其他版本请选各自的安装目录，不要选择其中的 `ChineseLauncher` 子目录。

没有快捷方式时，可以运行 `软件安装目录\ChineseLauncher\RizomUVChineseLauncher.exe`。直接运行原版 `rizomuv.exe` 或原版快捷方式会使用英文界面。需要打开模型时，先启动中文版，再在软件内打开文件；补丁不会接管文件双击关联。

安装包已包含汉化所需文件，使用时不需要安装 Python、Qt SDK 或开发工具。

## 版本兼容性

要求 **Windows 10 1607 或更高版本的 x64 系统**，包括 Windows 11，以及 x64 版 RizomUV。

| RizomUV 版本 | 验证状态 |
| --- | --- |
| 2027.0.598 | 已离线核对 HTML 提示入口和宿主完整性，提示翻译回归通过；尚未逐面板验证实际显示和复杂工程操作 |
| 2025.0.104 | 2026-09 的既往记录验证了加载和绘制接口；本轮未运行该版本，复杂工程和所有面板尚未逐项验收 |
| 2022.1.57 | 原始安装器中的程序已通过静态接口检查，尚未完成实际界面验证 |
| 2018.0.222 | 原始安装器中的程序已通过静态接口检查，尚未完成实际界面验证 |
| 其他 x64 版本 | 可选择对应目录安装，但需要实际验证显示效果 |

补丁不锁定软件版本号。若新版更换文字绘制方式，或调整界面布局，部分文字或顶部署名的位置仍可能需要适配。**能够安装不等于全部界面已经验证兼容。**

## 翻译范围

词典覆盖菜单命令、工具栏和面板标签、UV 集、岛与岛组、选择与变换、展开与排布、导入导出选项及提示说明。本轮根据本机 2027.0.598 程序及界面截图分批审校，合计新增 1,108 条映射并修订已有译文，保留全部旧英文键。详见 [翻译审查记录](docs/translations-2026-10-14.md)。

词条数不是界面覆盖率。动态拼接文字、未收录的提示、使用其他绘制接口的内容，以及部分按字形或逐字符处理的文字，仍可能显示英文。固定宽度控件也可能出现中文截断。

汉化在本机加载词典，不使用在线或本机机器翻译服务。菜单栏的蓝色链接可打开作者主页和项目仓库。

## 更新与自定义词典

关闭 RizomUV，运行新版安装器，选择原来的软件目录覆盖安装。

更新会替换未经修改的正式词典；人工修改的 `ChineseLauncher\dictionary_zh.json` 会保留，新版默认词典放在 `.inno\defaults` 供对照。安装恢复快照在成功后清理，不能作为长期备份。

如需自行补词，编辑词典的 `translations` 对象，保留英文键，在右侧填写中文值。文件须为 UTF-8 JSON；键不能重复，标点、空格和换行会参与匹配。修改后重新启动中文版生效。格式错误时运行时会保留英文并记录原因，不会加载部分损坏的词典。

同一安装器一次只管理一个 RizomUV 安装目录。更换软件目录前，先卸载旧目录中的中文补丁，再安装到新目录。

## 卸载与恢复英文

保存工程并退出软件，在 Windows“设置 → 应用 → 已安装的应用”中卸载 **RizomUV 中文补丁**。

卸载仅删除补丁拥有的文件，保留人工修改的词典、设置和额外文件。存在用户文件时 `ChineseLauncher` 文件夹会保留；RizomUV 原程序、模型和工程不在卸载范围内。

临时使用英文界面无需卸载，直接打开原版快捷方式即可。

## 常见问题

### 安装后仍显示英文

确认使用的是“RizomUV 中文版”快捷方式，并核对它指向的软件安装目录。若仅部分文字是英文，请按下文提供截图；若所有文字都未翻译，请检查运行日志。

### 安装器提示目录无效或程序正在运行

目录中应直接包含 x64 版 `rizomuv.exe`。保存并正常退出该目录下的 RizomUV 后重试。安装器不会强制关闭软件，也不接受目录链接或网络共享路径。

### 启动时提示运行时或词库缺失

重新运行安装器，并检查安全软件是否隔离了 `RizomUVChineseRuntime.dll`。启动器加载 DLL 失败时会显示错误并结束这次启动。若软件能打开但仍为英文，也请查看日志中的词典加载结果。

### 去哪里查看日志

优先查看 `软件安装目录\ChineseLauncher\RizomUVChineseRuntime.log`。目录不可写时，日志改存到 `%LOCALAPPDATA%\RizomUVChinese\RizomUVChineseRuntime.log`；将此路径粘贴到资源管理器地址栏即可打开。旧日志超过约 256 KiB 后会在下次启动时轮换为 `.previous`。

### 漏译、错译或文字排版有问题

请在 [项目 Issues](https://github.com/iillya/RizomUVChinese/issues) 提供完整软件版本号、问题截图、出现该界面的操作步骤和运行日志。排版问题请同时注明 Windows 显示缩放比例；截图尽量包含所在面板，方便判断词义。
